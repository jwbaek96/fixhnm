02 / 작업 상세

항목을 누르면 작업 내용과 포함·제외 범위를 확인할 수 있습니다.

공통 작업 / 4개 항목

01웹사이트 메뉴 구조 및 헤더 개편60만 원
  • 페이지 헤더를 1단에서 2단 구조로 변경합니다.
  • 기존 대메뉴 7개를 4개로 재구성하고, 메뉴 3개는 상단 소메뉴로 이동합니다.
  • 기존 드롭다운 메뉴를 메가 메뉴 방식으로 변경합니다.
  • 기능 테스트, 오류 수정 및 안정화 작업을 포함합니다.

산정 기준 고정 견적은 60만 원(VAT 별도)으로 제안합니다. 기존에 구현된 헤더·메가 메뉴는 중복 청구하지 않으며, 실제 요청된 변경·테스트 범위에 한해 적용합니다.

02페이지 상단 배너 디자인기준 48만 원
  • 페이지 제목·설명을 담는 상단 배너의 색상, 글자 크기, 간격 및 박스 디자인을 통일합니다.
  • 공통 스타일을 적용하고, 각 페이지의 제목·설명 길이에 따른 화면 배치를 확인합니다.

제외 항목 배너 이미지 제작 및 페이지별 문구 작성은 포함하지 않습니다.

03헤더 스크롤 동작 및 본문 대표 이미지기준 128만 원
  • 2단 헤더는 스크롤 시 화면에 고정되지 않도록 변경합니다.
  • 페이지 섹션 메뉴만 스크롤에 따라 상단에 붙도록 sticky 동작을 적용합니다.
  • 본문 상단에 대표 이미지 영역을 마련하고 제공된 이미지를 적용합니다.

확인사항 실제 적용 페이지 수와 이미지별 배치 차이에 따라 견적이 조정될 수 있습니다. 이미지 제작·보정·구매는 포함하지 않습니다.

04공통 섹션 제목·설명 영역기준 48만 원
  • ‘COMPANY INFO’ 같은 영문 라벨, ‘회사 개요’ 같은 제목, 제목 아래 설명문 블록을 정리합니다. 페이지 최상단의 큰 배너와는 별도인 본문 영역입니다.
  • 여러 페이지에서 반복되는 블록의 글꼴 크기·색상·굵기·줄 간격·여백을 통일합니다.
  • 섹션 성격에 따라 좌측 또는 중앙 정렬을 적용합니다.
  • 모바일 화면에서 제목과 설명이 잘 보이는지 확인합니다.

제외 항목 문구 작성·번역, 페이지마다 완전히 다른 개별 디자인은 별도 작업입니다.

별도 항목

05홈페이지 · 메인기준 180만 원
  • 메인 히어로를 현장 인물 사진·중앙 문구에서 건축물 사진·좌측 문구 구성으로 변경합니다.
  • 회사소개 영역의 제목·설명·버튼 배치를 조정합니다.
  • 사업분야를 카테고리 묶음에서 8개 카드 그리드로 변경합니다.
  • 아카데미 소개를 두 개의 가로형 과정 카드로 재구성합니다.
  • 문의 영역을 소개 문구, 연락처 카드, 바로가기 버튼이 있는 디자인으로 변경합니다.

중복 산정 없음 팝업 기능 수정은 아래 별도 항목(기준 12만 원)입니다. 공통 페이지 배너·섹션 제목은 공통 작업에 포함합니다. 푸터는 비교 이미지에서 큰 구조 변화가 확인되지 않아 별도 작업으로 산정하지 않았습니다.

06홈페이지 · 팝업 기능 수정기준 12만 원
  • 팝업이 2개일 때 기존 그리드 배치를 유지합니다.
  • 팝업이 1개만 표시되면 화면 중앙에 오도록 정렬합니다.
  • Esc 키를 눌러 열려 있는 팝업을 닫을 수 있도록 키보드 동작을 추가합니다.
  • 팝업 열기·닫기 및 기존 2개 팝업 배치가 유지되는지 확인합니다.

제외 항목 팝업 디자인 및 관리 기능 변경은 포함하지 않습니다.

07회사소개 · 기업현황기준 100만 원
  • 회사 소개와 회사 정보를 이미지·요약 정보·상세 주소가 구분되도록 재배치합니다.
  • 인사말을 대표자 사진과 인용형 제목이 있는 좌우 구성으로 변경합니다.
  • 회사 연혁 디자인을 정리하고 제공된 최신 연혁 내용을 반영합니다.

범위 구분 공통 배너·섹션 제목·대표 이미지 공통 영역은 공통 작업에 포함합니다. 사진 촬영·보정, 연혁 문구 작성·검수 및 번역은 포함하지 않습니다.

08(주)와이피피 아카데미기준 136만 원
  • 교육 소개 문구와 대표 이미지를 배치하도록 소개 영역을 변경합니다.
  • Relay School·PSAC 통계와 전체 수료 인원 강조 영역을 재구성합니다.
  • 교육 비전을 핵심 가치 카드로 표현합니다.
  • 교육 사진을 크게 보여주는 가로형 갤러리로 변경합니다.
  • 교육 연혁을 간결한 목록으로, 교육 장점을 카드형으로 정리합니다.

범위 구분 통계·문구·사진이 제공된다는 전제입니다. 공통 배너·섹션 제목·대표 이미지 영역 및 홈페이지의 아카데미 소개 카드는 이 항목에서 제외합니다. 신규 통계 또는 갤러리 관리 기능은 포함하지 않습니다.
